01 • Core understanding

UOTR Registration का मतलब

Manual का purpose candidate को portal के माध्यम से UOTR registration करके account बनाने की प्रक्रिया समझाना है।

📧 Email ID

Candidate की अपनी और working email ID verification के लिए ready होनी चाहिए।

📱 Mobile Number

Candidate का अपना और working mobile number verification के लिए ready होना चाहिए।

🪪 One-time Profile

Registration के बाद login करके one-time profile complete करने पर UOTR number प्राप्त होता है।

सबसे जरूरी बात: Registration successful होने के बाद process वहीं खत्म नहीं होता। Manual के अनुसार login करके one-time profile complete करना जरूरी है, तभी UOTR number मिलेगा।
02 • Step-by-step

Candidate Registration — पूरा Flow

नीचे का sequence manual के sections 3.1 से 3.6 के अनुसार है।

1

Portal खोलें और Registration पर जाएँ

✓ Done
  • Browser में https://nra.gov.in/uotr खोलें।
  • UOTR homepage आने के बाद top navigation में Candidate Registration चुनें।
  • Dropdown में Step 2: Enter Email ID & Mobile No. for Registration चुनें।
ध्यान दें: Menu में Step 2 registration entry दिखाई गई है; आगे खुलने वाले registration page में process indicator 1. Instructions → 2. Verify Email ID → 3. Verify Mobile No. → 4. Create Password दिखाता है।
2

Instructions पढ़ें और Proceed करें

✓ Done
  • Unified OTR System for Candidates का Instructions page खुलेगा।
  • सभी instructions ध्यान से पढ़ें।
  • “I hereby declare that I have read and understood the above instructions” checkbox tick करें।
  • Checkbox tick होने के बाद Proceed for Registration button active होगा।
  • Proceed for Registration पर click करें।
Instructions screen पर मुख्य बातें: एक active mobile और अपनी email रखने, secure password बनाने, one-time profile complete करने, unique UOTR number मिलने और गलत information देने की स्थिति से जुड़े निर्देश PDF screenshot में दिखते हैं।
3

Email ID Verify करें

✓ Done
  • Step 2: Verify Email ID page खुलेगा।
  • Valid email address Email ID field में enter करें।
  • Image में दिखा CAPTCHA enter करें।
  • Declaration accept करें।
  • Get OTP click करें; OTP entered email address पर भेजा जाएगा।
  • Inbox/Spam में OTP check करें।
  • OTP और CAPTCHA enter करके Verify Email ID click करें।
OTP नहीं मिला: Resend OTP click किया जा सकता है। Manual के अनुसार 3 resend attempts available हैं।
4

Mobile Number Verify करें

✓ Done
  • Step 3: Verify Mobile No. page खुलेगा।
  • Valid 10-digit mobile number enter करें।
  • CAPTCHA enter करें।
  • Declaration accept करें।
  • Get OTP click करें; OTP entered mobile number पर SMS से आएगा।
  • Mobile पर OTP check करें, OTP enter करें और CAPTCHA भरें।
  • Verify Mobile No. click करें।
OTP नहीं मिला: Resend OTP option है और manual के अनुसार 3 resend attempts available हैं।
5

Password Create करें

✓ Done
  • Step 4: Create Password page खुलेगा।
  • Password Policy ध्यान से पढ़ें।
  • Password field में policy के अनुसार password डालें।
  • Confirm Password में वही password दोबारा डालें।
  • Strength indicator में Strong होना सुनिश्चित करें।
  • Create Password click करें।
🔐 Exact Password Policy देखें
6

Registration Successful

✓ Done

Successful password creation के बाद screen पर success pop-up दिखाई देता है। Screenshot में “Congratulations! You have been successfully onboarded on Portal” message दिखाया गया है।

Next: Success के बाद candidate को login करके one-time profile complete करनी है।
7

Login → One-time Profile → UOTR Number

✓ Done

Manual के note के अनुसार registration के बाद login करके one-time profile complete करनी होगी। इसके बाद candidate को UOTR number प्राप्त होगा।

Profile के बारे में PDF instruction: Profile में identity, personal profile, educational details, disability, ex-servicemen और अन्य required relevant information से जुड़े details शामिल होने की बात screenshot में दी गई है।
03 • Exact policy from PDF screenshot

🔐 Password Policy

PDF के page 7 के screenshot में निम्न rules दिखाई गई हैं। इन्हें agent reference के लिए उसी अर्थ में रखा गया है।

01Password में कम से कम 8 characters होने चाहिए।
02कम से कम 1 uppercase letter होना चाहिए, जैसे A–Z।
03कम से कम 1 lowercase letter होना चाहिए, जैसे a–z।
04कम से कम 1 number होना चाहिए, जैसे 0–9।
05सिर्फ allowed special characters का उपयोग करें। PDF screenshot में examples दिए गए हैं: @ $ % & + = ! ? . _ -
06Password 25 characters से अधिक नहीं होना चाहिए।
07Password में spaces या tabs नहीं होने चाहिए।
08Password में repeated characters नहीं होने चाहिए, उदाहरण: aaa, 111।
09Password all numbers नहीं होना चाहिए।
10Password all alphabets नहीं होना चाहिए।
Final check: Password strength indicator में Strong दिखना चाहिए, फिर Create Password click करें।

05 • Agent technique

🎧 Call Handling — Simple Method

① Stage पहचानें

पहले पूछें: “आप registration के किस step पर problem face कर रहे हैं—Instructions, Email, Mobile, Password या Registration successful होने के बाद?”

② Screen पर क्या दिख रहा है?

Customer से exact button/message पूछें। इससे सही manual step identify करना आसान होगा।

③ उसी process में guide करें

Email OTP के लिए inbox/spam और resend option; mobile OTP के लिए SMS और resend option; password के लिए exact policy check करें।

④ Next action confirm करें

Customer से confirm करें कि वह अगले step पर पहुँच गया है या नहीं। Registration successful होने पर profile completion वाला next step जरूर बताएं।

Agent safety rule: Manual में जो detail नहीं दी गई है, उसके लिए अपनी तरफ से exact rule, limit या promise न बनाएं। अगर issue manual से बाहर हो, तो उसे unsupported assumption से solve न करें।
